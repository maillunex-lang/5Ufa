# Правила боя: что решено при реализации

Все числа тестовые и лежат в данных (`content/game.json` → `battle`, героя/врага, этапа).

| Вопрос из спецификации | Принято сейчас |
| --- | --- |
| Частота тиков | 0,1 с игрового времени, лимит 90 с = 900 тиков |
| Цель | Ближайший живой противник; сохраняется, пока жива, затем выбирается заново. Ничья — меньший слот |
| Урон | `атака × множитель × 100 / (100 + защита)`, минимум 1 |
| Энергия | +10 за действие (кроме главной), +5 за полученный удар, максимум 100; главная сбрасывает в 0. Только у героев с главной способностью |
| Приоритет готовых способностей | главная > обычный навык (по кулдауну) > базовая атака |
| Лечение | Союзник с минимальным % здоровья (включая себя); ничья — меньший слот; все здоровы — лечение не тратится, идёт базовая атака |
| Движение | Подбегает к личной точке рядом с целью (смещение по слоту), без расталкивания |
| Тайм-аут | Победа защитника |
| Воспроизводимость | Бой детерминирован по `seed`, сохраняется весь список событий; повторный запрос результата не выдаёт награду |
