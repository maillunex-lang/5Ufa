# Принятые решения

| Вопрос | Решение | Дата |
|---|---|---|
| Адрес сервера | `https://tts-ufa.ru/games/server` — за основным веб-сервером VPS | 2026-11-03 |
| Порт игры на VPS | `8085`, слушает только `127.0.0.1` (снаружи — только через HTTPS основного сайта) | 2026-11-03 |
| HTTPS | Сертификат домена tts-ufa.ru, уже обслуживаемый основным Nginx | 2026-11-03 |
| ID Android-приложения | `lunex.ufa` (игра), `lunex.ufa.admin` (админка) | 2026-11-03 |
| Движок | Godot 4.7.2, рендер GL Compatibility, только arm64-v8a | 2026-11-03 |
| Языки | Только русский (структура локализации позволяет добавить язык позже) | 2026-11-03 |
| Время бэкапа | 05:00 по Уфе = `BACKUP_HOUR=0` (UTC) | 2026-11-03 |
| Название игры | Пока `[НАЗВАНИЕ]`, меняется в `config/game_settings.json` / админке | — |

> ID приложений после публикации в RuStore изменить нельзя.
> Минимальная версия Android в APK — 7.0 (так собирает Godot без Gradle); целевая — 16 (SDK 36).
> Игра рассчитана и проверяется на Android 12+.
