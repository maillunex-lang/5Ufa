# Админка (этап 6)

Отдельное приложение **«[НАЗВАНИЕ] Админка»** (`lunex.ufa.admin`). Это тот же Godot-проект, что игра
(`client/`), но с другой главной сценой (`client/admin/`) и своим пресетом экспорта «Admin Android». Поэтому
предпросмотр показывает **настоящие экраны игры** на данных черновика. Код админки в APK игры не попадает
(CI это проверяет).

APK админки лежит в GitHub Releases рядом с игрой: `ufa-admin-<версия>.apk`. В приложении нет паролей и ключей —
без логина и пароля администратора оно бесполезно.

## Первый запуск: создать администратора на VPS

Пароль задаёте вы, он хранится только в базе (в виде хэша). В коде, логах и GitHub его нет.

```bash
cd ~/ufagame
docker compose exec -it api python -m app.cli admin create owner
```
Команда спросит пароль дважды (на экране он не виден). Нужно от 10 символов, буквы и цифры.
Ожидаемый результат: `Создан администратор owner (роль owner)`.

Другие команды:

| Команда | Что делает |
|---|---|
| `docker compose exec -it api python -m app.cli admin set-password owner` | Сменить пароль и выйти на всех устройствах |
| `docker compose exec api python -m app.cli admin list` | Список администраторов, последний вход |
| `docker compose exec api python -m app.cli admin 2fa-enable owner` | Включить 2FA: покажет ключ для «Яндекс Ключ» / Google Authenticator |
| `docker compose exec api python -m app.cli admin 2fa-disable owner` | Выключить 2FA |

## Безопасность

- 5 неудачных попыток входа за 15 минут (с одного адреса или на один логин) — блокировка на 15 минут.
- Сессия закрывается после 7 дней без действий (`ADMIN_SESSION_DAYS` в `.env`). Кнопка «Выйти» закрывает сразу.
- Роли: `owner` — всё; `editor` — контент; `moderator` — игроки (этап 6б). Сейчас администратор один — владелец.
- **Журнал действий**: каждый вход (и неудачный), каждая правка, загрузка файла, патч, публикация и откат —
  с временем, логином и адресом. Смотреть: «Журнал».

## Как вносить изменения

1. **Разделы** → объект → форма (поля по JSON Schema, подписи и подсказки на русском) или «Как JSON».
   «Сохранить в черновик» — сервер сразу проверяет по схеме и показывает ошибки списком.
2. **Картинки и файлы** раздела: нажмите на картинку → «Заменить», или «+ Загрузить новый файл».
3. **ZIP-патч** (формат `docs/patch-format.md`): выбрать ZIP → список «что добавится / изменится / удалится»
   и ошибки → «Применить в черновик».
4. **Черновик**: все правки одним списком, «Отменить» у каждой, «Сбросить весь черновик».
   - «Отправить на тест» — версию видят только тестовые аккаунты (канал `test`);
   - «Опубликовать сразу для всех» — с подтверждением.
5. **Версии**: любая прошлая версия → «Откатить сюда» (для всех игроков, мгновенно) или «На тест».
   Проверенную на тесте версию — «Для всех».

Черновик один общий. Если версию игры поменяли (откат), админка предложит «Перенести черновик на текущую версию».

## В каждом разделе

- «Промпт для ИИ» — копирует в буфер готовый промпт: схема раздела, текущие объекты, пример, правила ZIP.
  Тот же текст для базового контента — в `/patch-prompts/<раздел>.md` (`scripts/gen_patch_prompts.py`).
- «Выгрузить ZIP» — раздел целиком в формате патча (бэкап и пример для ИИ).

## Предпросмотр

Админка скачивает файлы черновика (только изменённые) и показывает:
- главный экран — здания можно перетаскивать пальцем и сохранить расположение в черновик;
- героев — портрет, характеристики и все анимации (покой, ходьба, атака, умения, удар, смерть, победа);
- карту кампании — главы, карта, диалоги, этапы, враги и награды;
- экраны игры как у игрока (главный, герои, инвентарь, призыв, кампания, тестовый бой) — кнопка «← Админка»
  возвращает обратно. Для этого админка входит как отдельный гость-игрок.

## Веб-версия (браузер ПК)

Та же админка открывается в браузере: **https://tts-ufa.ru/games/server/admin/** (после деплоя и сборки APK
она обновляется автоматически). Вход — тем же логином и паролем. Файлы (ZIP, картинки) выбираются окном
браузера, выгрузки сохраняются в папку «Загрузки».

## Игроки (этап 6б)

- Поиск по номеру (`#1001`), имени или почте; карточка: герои, кошелёк, прогресс кампании, предметы, устройства.
- «Изменить ресурсы»: валюта, число (`500` — добавить, `-500` — списать), **причина обязательна** — попадает
  в журнал вместе с балансом до и после. В минус уйти нельзя.
- «Сделать тестовым» — аккаунт видит канал `test` (проверка черновика перед публикацией).
- Бан на N дней с причиной (игрок её видит), «Снять бан».

## Бэкапы и версии APK (этап 6б)

- **Бэкапы**: список, «Сделать бэкап сейчас» (начнётся в течение 30 секунд). Восстановление — только на VPS:
  `cd ~/ufagame && bash scripts/restore.sh <имя_папки>` (перед ним автоматически делается свежая копия).
- **Версии APK**: выключить неудачную версию, сделать обязательной / необязательной.

## Редактор анимации и частей героя

«Предпросмотр» → «Герои и анимации» → герой → «Редактор анимации и частей героя»:
- выбор анимации (длительность, цикл), кости, шкала времени; ключи кости — кнопками (нажмите — перейти);
- поворот / сдвиг / масштаб ползунками или **пальцем по герою** (режимы «Поворот», «Сдвиг») — ключ ставится
  в текущий момент; «Удалить ключ здесь», «Сбросить кость», «Проиграть»;
- «+ Анимация» (стандартные: skill2, run и др.), «Удалить анимацию» (обязательные idle/attack/hit/death нельзя);
- события: `hit` — момент удара, `projectile` — вылет снаряда (кнопка «Сейчас» ставит текущее время);
- части героя: «Скачать», «Заменить» (новая картинка сразу видна), «+ Добавить часть на выбранную кость»;
- «Сохранить анимации в черновик» → тест / публикация как обычно.

## Деплой и правки из админки

При деплое контент из репозитория больше **не затирает** правки из админки: переносятся только файлы,
изменённые в репозитории с прошлого деплоя, поверх текущей версии игры (версия «репозиторий + правки админки»).
Пустой черновик автоматически переводится на новую версию.

## API

Все пути — `/api/v1/admin/...`, заголовок `Authorization: Bearer <токен>`; ответы об ошибках контента —
`422 {"detail": {"message", "errors": [...]}}`.

| Метод | Путь | |
|---|---|---|
| POST | `/auth/login` | `{login, password, code?}` → токен |
| POST | `/auth/logout`, GET `/me`, GET `/audit` | выход, кто я, журнал |
| GET | `/sections`, `/sections/{id}` | разделы, объекты и файлы раздела |
| GET/PUT/DELETE | `/sections/{id}/objects/{oid}` | объект раздела (`{data, create}`) |
| GET/PUT/DELETE | `/files?path=` | файл черновика (PUT — тело запроса = файл) |
| GET | `/schemas/{name}` | JSON Schema для форм |
| GET | `/draft`; POST `/draft/revert`, `/draft/rebase`, `/draft/test`, `/draft/publish` | черновик |
| GET | `/releases`; POST `/releases/{id}/publish` | версии, публикация, откат |
| POST | `/patches/preview`, `/patches/apply` | ZIP-патч (тело = ZIP) |
| GET | `/sections/{id}/export`, `/sections/{id}/prompt` | выгрузка ZIP, промпт для ИИ |
