# Прогрессия героев и призыв (этап 5а)

Все правила — данные в контенте, правятся без обновления APK (позже — в админке):
- `content/config/progression.json` — редкости, уровни, вознесение, кристалл, старт (схема `progression.schema.json`);
- `content/summon/banners.json` — баннеры, шансы, гарант (схема `summon.schema.json`).

Всё считает сервер. Каждое изменение игрока (награды, валюта, герои, призыв) выполняется под блокировкой
строки игрока в PostgreSQL — параллельные нажатия не тратят валюту дважды (проверено на 20 одновременных запросах).

## Коллекция и стартовый набор

- Каждый экземпляр героя — отдельная «копия» (нужны для вознесения).
- Новый и уже существующий игрок один раз получает: 5 элитных героев (Алпамыша, Урал-батыр, Заятуляк, Хумай,
  Хыухылу), 10 свитков призыва, 1000 кристаллов. Пройденные этапы, золото и опыт сохраняются.
- В кампании и (для обычных игроков) в тестовом бою — только свои герои; берётся сильнейший экземпляр.
  Тестовые аккаунты в тестовом бою могут брать любых героев (базовые характеристики).
- Предел коллекции — 300 героев.

## Редкости и уровни

| Ступень | Предел уровня | Множитель характеристик |
|---|---|---|
| Редкий | 60 | 0,85 |
| Элита | 100 | 1,0 |
| Элита+ | 120 | 1,15 |
| Легенда | 140 | 1,3 |
| Легенда+ | 160 | 1,45 |
| Миф | 180 | 1,65 |
| Миф+ | 200 | 1,85 |
| Вознесённый | 240 | 2,2 |

Характеристики = базовые × множитель ступени × (1 + 2% × (уровень − 1)).
Стоимость уровня L→L+1: золото `round(15 × L^1.2)`, опыт `round(10 × L^1.25)`, с 100-го уровня ещё эссенция.

## Кристалл резонанса

- 5 сильнейших героев (по уровню) качаются обычно; герои в кристалле получают уровень 5-го из них
  (не выше предела своей редкости). 5 мест. Героев в кристалле нельзя повышать вручную.
- Работает, когда вне кристалла не меньше 5 героев. Убрали из кристалла — вернулся собственный уровень.

## Вознесение (корм подбирается сервером автоматически)

| Из → в | Нужно |
|---|---|
| Элита → Элита+ | 1 элитная копия того же героя |
| Элита+ → Легенда | 1 элитная копия того же героя + 1 элитный герой той же фракции |
| Легенда → Легенда+ | 1 легендарная копия того же героя |
| Легенда+ → Миф | 2 героя той же фракции (Легенда+) |
| Миф → Миф+ | 1 элитная копия того же героя + 1 герой той же фракции (Миф) |
| Миф+ → Вознесённый | 2 героя той же фракции (Элита+) |

Герои в кристалле в корм не идут. Простые (редкие) герои распускаются в 100 эссенции.

## Призыв

| Результат | Шанс |
|---|---|
| Редкий герой (6 простых героев, по одному на фракцию) | 51,6% |
| Элитная копия героя пула | 43,7% |
| Легендарная копия | 4,7% |

- Гарант: легенда не позже 30-го призыва на баннере (счётчик сбрасывается при легенде).
- Самый первый обычный призыв — легенда.
- Баннеры: обычный (свиток или 300 кристаллов), фракционные (свиток фракции), временный «Хумай» (270 кристаллов,
  половина легенд — Хумай). Небожители и Подземное царство в обычный пул не входят (будут в особых баннерах).
- Призыв дружбы — этап 8 (вместе с друзьями).

## Новые источники

- Первая победа в этапе: +20 кристаллов; последний этап главы: +1 свиток.
- AFK-сундук в час: +5 кристаллов и +10 эссенции (с той же прибавкой за этапы, что золото и опыт).

## API

| Метод | Путь | |
|---|---|---|
| GET | `/api/v1/heroes` | Коллекция, кошелёк, кристалл (выдаёт стартовый набор при первом вызове) |
| POST | `/api/v1/heroes/{id}/level-up` | `{times}` — повысить уровень |
| POST | `/api/v1/heroes/{id}/ascend` | Вознести (корм выбирает сервер) |
| POST | `/api/v1/heroes/{id}/crystal` | `{put: true/false}` — в кристалл / из кристалла |
| POST | `/api/v1/heroes/{id}/dismiss` | Распустить простого героя в эссенцию |
| GET | `/api/v1/summon` | Баннеры, шансы, гарант, кошелёк |
| POST | `/api/v1/summon` | `{banner, count: 1 или 10}` |
