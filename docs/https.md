# HTTPS — нужно ваше решение

Сейчас игра работает по HTTP на порту `HTTP_PORT`. Для закрытого теста этого хватит,
для публичного релиза нужен HTTPS (пароли игроков, требования магазинов).

Android по умолчанию запрещает приложениям незашифрованный HTTP — на этапе 2 для
тестовой сборки разрешим HTTP явно только для адреса вашего VPS, а в релизной — только HTTPS.

## Варианты

### А. Есть домен (рекомендую)
Подойдёт поддомен, например `game.ваш-домен.ru` (A-запись на IP VPS).
Сертификат Let's Encrypt — бесплатно, продлевается автоматически.

- Если порты **80 и 443 свободны** — Nginx игры займёт их сам, certbot в отдельном контейнере.
- Если **80/443 уже заняты** вашим Nginx/Apache (частая ситуация) — игру не трогаем на её порту,
  а в вашем существующем веб-сервере добавляем один блок `server` для поддомена,
  который проксирует на `127.0.0.1:HTTP_PORT`, и выпускаем сертификат через certbot.
  Ваши текущие сайты это не затрагивает.

### Б. Домена нет
- Купить домен `.ru` (~200–600 ₽/год у reg.ru, nic.ru и др.) и перейти к варианту А.
- Бесплатный поддомен (например, DuckDNS) + Let's Encrypt — работает, но надёжность ниже,
  для публичного релиза не рекомендую.

Скажите, какой вариант выбираете и заняты ли у вас порты 80/443 (`sudo ss -tlnp`),
и я подготовлю точные команды.
