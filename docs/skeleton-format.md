# Формат скелетной анимации героя (ufa-skeleton v1)

Открытый формат: части тела — PNG, описание — `skeleton.json` (схема `shared/schemas/skeleton.schema.json`).
Клиент собирает героя из частей во время игры. Чтобы заменить внешность героя (например, на ИИ-арт),
достаточно заменить PNG и при необходимости поправить точки `pivot` — код не меняется.

## Папка героя

```
heroes/<id>/
├── hero.json          — характеристики, навыки, тексты (shared/schemas/hero.schema.json)
├── skeleton.json      — кости, части, анимации
├── portrait.png       — портрет 128×128 (списки, кнопки ультимейтов)
├── full.png           — полный арт (карточка героя)
├── projectile.png     — снаряд (только стрелки, маги, поддержка)
└── parts/*.png        — части тела
```

## Система координат

- Пиксели, **ось Y вниз**, начало (0,0) — **под ногами** героя.
- Герой **смотрит вправо**. Враги зеркалятся клиентом автоматически.
- Углы в градусах, **по часовой стрелке**. Рука в покое висит вниз; `-90` — вытянута вперёд, `-160` — поднята вверх.

## Разделы skeleton.json

| Раздел | Что описывает |
|---|---|
| `bones` | Кости: `name`, `parent`, смещение `x`,`y` от родителя, `rotation` в покое |
| `slots` | Картинки частей: `bone`, `image` (путь от папки героя), `pivot` — точка картинки, совпадающая с костью. **Порядок = порядок отрисовки** (первая — сзади) |
| `anchors` | Точки: `projectile` (откуда летит снаряд), `hit` (куда попадают удары), `overhead` (над головой — полоски здоровья) |
| `animations` | `idle`, `walk`, `attack`, `skill`, `ultimate`, `hit`, `death`, `victory` |

## Анимация

```json
"attack": {
  "duration": 0.6,
  "loop": false,
  "bones": {
    "arm_front": {"rotate": [[0, 0], [0.22, -150], [0.35, 30], [0.6, 0]]},
    "root": {"translate": [[0, 0, 0], [0.35, 6, 0], [0.6, 0, 0]], "scale": [[0, 1, 1], [0.6, 1, 1]]}
  },
  "alpha": [[0, 1], [0.6, 1]],
  "events": [{"t": 0.35, "name": "hit"}]
}
```

- Ключи `[время_сек, значение]` (поворот) или `[время_сек, x, y]` (сдвиг, масштаб). Между ключами — плавный переход.
- Значения — **добавка к позе покоя** (поворот и сдвиг) или множитель (масштаб).
- `events`: `hit` — момент удара, `projectile` — вылет снаряда.
  Для синхронности с боем: в `attack` событие должно совпадать с `attack_windup_ms` роли
  из `config/battle.json` (ближний бой 0,35 с, дальний 0,4 с), в `skill`/`ultimate` — с `cast_time_ms` навыка.

## Правила для ИИ-арта

- PNG с прозрачным фоном, без обрезки краёв частей; лучше рисовать в 2× и сохранять в нужном размере.
- Размер героя ≈ 100×140 px в позе покоя (поле `size`).
- Имена файлов — латиница в нижнем регистре: `parts/arm.png`, `parts/weapon.png`.
- Обе руки могут использовать одну картинку `parts/arm.png`, обе ноги — `parts/leg.png`.

## Импорт готового вырезанного рига

Если художник прислал риг в виде слоёв на общем холсте (`assets/parts/*.png`) и файла костей
(`assets/bones.json`: `{"кость": {"pivot": [x, y], "parent": "родитель" | null}}`), его можно перевести в этот
формат одной командой:

    python3 scripts/import_cutout_rig.py путь/к/папке_рига humai

Скрипт обрезает слои, уменьшает их, собирает `heroes/<id>/skeleton.json` с анимациями боя, портрет и полный арт.
Слои кладутся в `heroes/<id>/rig/`. Такой герой больше не перерисовывается `scripts/gen_heroes.py`.
Сейчас так сделана Хумай (риг «Самрая», версия 2).

## Нарезка цельного рисунка

Если есть только один рисунок героя (вид сбоку, смотрит вправо):
1. Убрать фон (например, `rembg` с моделью `isnet-anime`).
2. Разметить части в `scripts/rigs/<герой>.json`: многоугольники частей (голова, плащ, руки, ноги; корпус — всё
   остальное), точки вращения, порядок отрисовки, стиль анимаций (`sword` — меч, `fist` — кулаки),
   при необходимости `shadow_cut` — убрать оставшуюся от фона тень.
3. Запустить `python3 scripts/import_flat_hero.py рисунок_без_фона.png ural_batyr`.

Так сделаны Урал-батыр (рисунок с мечом) и Алпамыша (фигура из листа персонажа). Скрытых частей на рисунке нет, поэтому движения сделаны небольшими, чтобы не было видно швов.

## Скины

Скин героя — те же `skeleton.json` и анимации, другие картинки. Файлы скина лежат в
`heroes/<герой>/skins/<скин>/` по тем же относительным путям, что у обычного вида (`rig/torso.png`,
`portrait.png`, `full.png`). Нет картинки в скине — берётся картинка обычного вида. Список скинов —
поле `skins` в `hero.json`: `{"id": "winter", "name": "Зимняя", "free": false}`.

Если скин нарезан из своего рисунка (нарезчик админки), пропорции частей могут отличаться — тогда у
части в `skeleton.json` есть своя картинка и точка крепления для скина:
`{"name": "head", ..., "skins": {"winter": {"image": "rig/head.png", "pivot": [40, 88]}}}`.
Картинка ищется в `skins/<скин>/` по этому пути.
