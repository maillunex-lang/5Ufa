# Бой

Бой считает **сервер** (`server/app/battle/sim.py`), клиент только проигрывает журнал событий.
Одинаковые отряды + seed → всегда одинаковый бой. Все числа — в контенте и правятся без обновления APK.

## Правила

- 5 на 5, вид сбоку. Слоты `0–1` — передний ряд, `2–4` — задний. Атакующие слева, защита справа.
- Расчёт по тикам: `tick_rate` (20 в секунду). Предел — `max_duration_sec` (90 с); **время вышло или погибли все — победа защиты**.
- Ближний бой подходит к цели, дальний стреляет с места. Цели по роли (`config/battle.json → roles.targeting`):
  убийцы идут к заднему ряду, остальные — к ближайшему. Бойцы ближнего боя переключаются на врага,
  оказавшегося заметно ближе (например, на прорвавшегося убийцу); стрелки и маги держат цель.
- Всё, что происходит в одном тике, срабатывает одновременно; порядок внутри тика случайный (по seed),
  поэтому ни одна сторона не получает систематического преимущества (проверяется тестом «зеркальный бой»).

## Формулы (`config/battle.json`)

```
урон = атака × множитель_навыка × (1 ± variance) × [крит: crit_damage] × [фракция: 1 + faction_bonus]
       × (1 − min(max_reduction, защита / (защита + defense_constant)))
```
- Круг фракций (`factions/factions.json → strong_against`): Батыры → Нечисть → Лесные духи → Кочевники → Батыры, +25%.
- Отдельная пара (как Небожители/Гипогеи в AFK Arena): **Небожители ⇄ Подземное царство** — +25% друг другу, с остальными нейтральны.
- Энергия (макс. `energy.max` = 1000): `on_attack` за обычную атаку, `on_hit_per_hp_percent` за каждый
  потерянный 1% здоровья, `on_kill` за убийство, `on_skill` за навык. При 1000 — ультимейт
  (автоматически, или по кнопке, если «Авто» выключено).

## Навыки (`hero.json → skills`)

| type | Когда срабатывает |
|---|---|
| `ultimate` | Полная энергия |
| `active` | По перезарядке `cooldown_ms` (первый раз — `first_cast_ms`), когда цель в досягаемости |
| `passive` | `trigger`: `battle_start` (в начале), `low_hp` (здоровье < 30%, один раз), `kill` (после убийства) |

Эффекты (`effects[].kind`): `damage`, `heal`, `shield`, `stun`, `buff` (± % к `atk`/`def`/`crit_chance`/`attack_speed`),
`dot` (урон каждую секунду), `energy`, `stat` (постоянный бонус, для пассивок).
Цели (`target.select`): `current`, `nearest`, `farthest`, `lowest_hp`, `highest_atk`, `frontline`, `backline`, `random`, `all`, `self`.

## API

| Метод | Путь | |
|---|---|---|
| GET | `/api/v1/battle/test-teams` | Готовые отряды противников |
| POST | `/api/v1/battle/test` | `{team:[{hero, slot}], enemy}` → `{log}` (ульты автоматически) |
| WebSocket | `/ws/battle/test` | Живой тестовый бой с ручными ультимейтами; заголовок `Authorization: Bearer <токен>` |

Для живого боя клиент отправляет после подключения `{team:[{hero,slot}],enemy}`.
Сервер отвечает `start` с начальными данными, затем `events` с событиями и полем
`until` (рассчитанный тик), наконец `end` с итогом. Команды игрока: `ult` с `uid`
своего героя, `auto` с логическим полем `on` и `skip`. Сервер проверяет команду и
сам решает, можно ли применить ультимейт. При потере соединения сервер включает
авто и досчитывает бой; результат тестового боя при этом не сохраняется.

## Журнал (`log.events`, схема `shared/schemas/battle_log.schema.json`)

Каждое событие: `t` (тик) и `e` (тип).

| e | Поля | Что показать |
|---|---|---|
| `move` / `stop` | `u`, `x`, `vx` | Начал/закончил движение (позиция меняется линейно со скоростью `vx`/сек) |
| `attack` | `u`, `target`, `projectile`, `hit_t` | Анимация атаки; снаряд долетает к тику `hit_t` |
| `cast` | `u`, `skill`, `kind`, `anim`, `impact_t` | Анимация навыка/ультимейта, срабатывает к `impact_t` |
| `impact` | `u`, `skill`, `targets` | Навык сработал (вспышка на целях) |
| `damage` | `src`, `u`, `amount`, `hp`, `kind`, `crit?`, `absorbed?` | Цифра урона, полоска здоровья |
| `heal` / `shield` | `u`, `amount`/`value` | Лечение / щит |
| `stun` / `buff` / `buff_end` / `dot` | `u`, `until`… | Значки состояний |
| `energy` | `u`, `value` | Полоска энергии |
| `passive` | `u`, `skill` | Сработала пассивка |
| `death` / `victory` / `end` | `u` / `winner` | Смерть, победная анимация, итог |

## Баланс (проверено на 100–400 боях)

| Проверка | Результат |
|---|---|
| Зеркальный бой (одинаковые отряды) | ~50% побед атакующих |
| Средняя длительность | 23–30 с |
| Батыры против «Отряда Шульгена» | ~54% побед |
