# Дорожная карта 5Ufa и параллельная разработка

Статус на 04.11.2026. Спецификация v1.0 — у владельца (этапы 0–9 ниже совпадают с её разделом 11). Правила работы — `AGENTS.md`, контракт — `docs/api.md`.

## Что уже есть
Сервер (бой, аккаунты, прогресс, награды, сброс уровней, техработы, бэкапы), каркас админки, тестовый контент, автодеплой на VPS (https://tts-ufa.ru/games/server/), клиент C-1…C-4 в первой версии (выбор «гость/войти», привязка аккаунта с резервным кодом, вход и восстановление, город, кампания и расстановка, герои и прокачка, воспроизведение боя на моделях с эффектами по образцу владельца: камера ~48°, круглая арена, панель героев с портретами из моделей, скорость x2 по прогрессу, обучение из данных) и сборка тестового APK в Actions. Проверка обновления по GitHub Releases есть (S-4): черновики, prerelease и старые `client-v0.1.x` не предлагаются. Бой запоминает версии файлов, бэкап включает `data/media`. Нет: финальных моделей и фонов, обычного релиза APK нового пакета.

## Трек A. Admin (этапы 4–5)
Порядок: A-1 вход/главная ✅ → A-2 ✅ (сделано: формы героев и врагов, общая библиотека способностей со ссылками, «где используется», анимация способности и просмотр на модели, баланс, этапы, арена и камера, обучение, панель «Сохранить»; **не сделано из A-2: массовые операции**) → A-3 кампания и арены (визуальная расстановка 5 позиций); **A-3b визуальный редактор камеры арены** с предпросмотром: ползунки и перетаскивание (позиция, точка взгляда, угол обзора, растяжение по глубине), предпросмотр на тех же моделях и фоне. Для точного совпадения с игрой предпросмотр — веб-сборка боевой сцены Godot во встроенном окне админки (экспорт HTML5 того же кода); запасной вариант — упрощённый просмотр на three.js. Параметры уже лежат в данных (`arena.camera`) и применяются со следующего боя → **A-4 ✅** медиатека (`docs/media.md`): GLB, картинки и фоны, папки, теги, лицензия, источник версии, промпт, «где используется», замена с просмотром и откатом, докачка клиентом. Бой запоминает версию файла, файлы медиатеки попадают в бэкап базы. → A-5 игроки (один аккаунт, журнал, бэкап перед опасным) → A-6 ZIP импорт/экспорт (всё или ничего) → A-7 конструктор способностей → A-8 конструктор интерфейсов. Интерфейс должен работать на телефоне и ПК, пути запросов — относительные (сайт стоит под `/games/server/`).
