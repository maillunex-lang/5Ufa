# Мир, сезоны и старые этапы

Схема версии 1: `schemas/world.v1.json`, проверка в `server/src/world.js`. Старый файл без блока `world` по-прежнему принимается, старые сохранения игроков не переписываются.

## Как устроено
Республика → район или город → место → цепочка заданий внутри сезона. Боевое задание только **ссылается** на номер уже существующего этапа (`stage: 1` … `10`). Награда и расчёт боя остаются у этапа. Сюжетная сцена награду не даёт.

Сезон `story` остаётся навсегда (`forever: true`). Сезоны `arena` и `event` — отдельно и сейчас пустые: режимы не сделаны. Один район может входить в несколько сезонов. Изменение места — запись `placeStates` для пары «место + сезон», а не правка прошлого сезона.

Условие открытия — одно из каталога: `always`, `stage:N`, `quest:id`. Своих формул у контента нет.

В одной версии контента не больше 400 записей каждого списка. Это технический предел, пока нет подгрузки карты частями. Пять тысяч единиц сейчас не создаются.

## Демонстрация
В `content/game.json` один фрагмент, помечен `_demo: true`.

- Факт: Бурзянский район и город Уфа есть в статье 64 Конституции Республики Башкортостан. Пещера Шульган-Таш (Капова) — в Бурзянском районе, на реке Белой, в заповеднике «Шульган-Таш». Источники лежат в полях `sources`.
- Вымысел: договор людей и духов, встреча с духом без памяти, искажённые существа. Имя духа, виновник и стартовый район — только варианты в `world.proposals`.
- У Уфы мест нет. Это пустая точка на карте, не спрятанный уровень.
- Прогресс этапов (`stage_progress`) не менялся. Просмотр сцены пишется отдельно (`story_progress`) и золото не трогает.

## Что видит игрок
Кампания: сезон → район → место → сцена или бой, ниже прежний список этапов 1–10 (обучение по-прежнему подсвечивает этап 1). После боя, если этап есть в цепочке, на результате написано место. Город показывает четыре здания и прямо говорит, что внутрь войти нельзя.

## Админка
Раздел «Мир и сезоны». У записей есть «где используется»; удалить запись со ссылками нельзя, сервер такое сохранение тоже отвергнет. Промпт — текст для внешнего ИИ, запрос к нему из игры не уходит.

Медиатека: у имени файла есть папка, теги, лицензия, требования и промпт. Карточка файла сохраняется сразу и копируется в следующую версию файла. Контент по-прежнему включается кнопкой «Сохранить» (сразу новая версия, с откатом). Отдельного серверного черновика нет: несохранённые буквы живут только в открытой вкладке, иначе каждое нажатие клавиши плодило бы версию.
