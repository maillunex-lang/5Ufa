# Главный экран «Город»

Всё оформление — данные в контенте, меняется без обновления APK (позже — в админке):
- `content/ui/hub.json` — здания (картинка, подпись, центр `x`/`y`, масштаб, действие, красная точка),
  боковые действия слева, кнопки «Почта»/«Настройки», нижняя навигация (схема `hub.schema.json`);
- `content/ui/hub/background.webp` — фон города 720×1400 (готовый арт, прокручивается по вертикали);
- `content/ui/hub/building_*.png`, `icon_*.png`, `emblem.png` — заглушки, нарисованные `scripts/gen_ui.py`;
  заменяются артом с теми же именами.

Действия: `{"scene": "heroes" | "summon" | "campaign" | "test_battle" | "hub" | "more"}` — открыть экран
(`more` — «Настройки»: аккаунт, проверка файлов, версия), `{"soon": "текст"}` — сообщение «появится позже».

Красные точки (`badge`): `heroes` — хватает ресурсов поднять уровень герою, `summon` — есть свитки призыва,
`campaign` — в AFK-сундуке есть награда или доступна быстрая награда.
