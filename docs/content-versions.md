# Версии контента (S-1)

- Контент игры (`content/game.json`) хранится в базе по версиям: `content_versions` (id, хеш, JSON, источник, автор, комментарий, родитель, время). Активна последняя версия.
- **Источники:** `file` (импорт файла из репозитория), `admin` (сохранение в админке), `rollback` (откат).
- **Бой закрепляет версию** в момент старта (`battles.content_version`): правки действуют со следующего боя, идущие бои и их повтор остаются на своей версии.
- **Откат** создаёт новую версию с содержимым выбранной. Аккаунты, ресурсы и прогресс игроков он не меняет (спецификация: откат контента отдельно от восстановления аккаунтов).
- **Проверка до записи** (`validateContent`): неверный контент не сохраняется, возвращаются причины. Защита от гонки: `baseVersion` должен совпадать с активной. Нельзя убрать героя, которым владеют игроки (удаление с компенсацией, задача S-5).
- **Журнал** (`audit`): каждое сохранение, откат и импорт файла записываются (кто, откуда, куда, комментарий, число изменений).
- **Файл `content/game.json` как «зерно»:** импортируется, когда изменился сам файл (по хешу) или на пустой базе. Если файл не менялся, деплой правки из админки **не затирает**. Если файл изменили в репозитории, при деплое появляется новая версия с содержимым файла (старые правки админки остаются в истории и доступны для отката). Пока контент правится кодом, файл остаётся источником; когда редакторы админки заработают, основным станет админка.
- Миграция существующих баз выполняется при открытии (`openDb`): добавляются колонки `source`, `author`, `parent`.
