# Снаряжение и уникальный предмет (этап 5б)

Все правила — данные в контенте `content/config/equipment.json` (схема `equipment.schema.json`), меняются без
обновления APK (позже — в админке). Всё считает сервер, под блокировкой игрока: параллельные нажатия не тратят
ресурсы дважды (проверено на PostgreSQL: из 20 одновременных улучшений прошли ровно столько, на сколько хватило руды).

## Слоты и типы

| Слот | Обычный предмет +0 даёт |
|---|---|
| Оружие | атака +20 |
| Доспех | здоровье +200, защита +8 |
| Шлем | здоровье +300 |
| Сапоги | атака +6, здоровье +120 |

Тип предмета должен совпадать с ролью героя: **Сила** — танк и воин (меч, латы, шлем, сапоги), **Ловкость** —
стрелок и убийца (лук, кожаный доспех, капюшон, лёгкие сапоги), **Мистика** — маг и поддержка (посох, мантия,
венец, туфли). Совпала фракция предмета с фракцией героя — характеристики предмета +15%.

## Редкость и улучшение

| Редкость | Множитель | Разбор, руды |
|---|---|---|
| Обычный | 1,0 | 2 |
| Редкий | 1,6 | 5 |
| Элитный | 2,56 | 12 |
| Легендарный | 4,1 | 30 |
| Мифический | 6,55 | 75 |

- Улучшение +0 … +10, каждый уровень +8% к характеристикам предмета.
- Цена L→L+1: золото `100 × (L+1) × (номер редкости)`, руда `3 × (L+1) × (номер редкости)` (обычный = 1, редкий = 2 …).
- Разбор: руда по таблице + 50% руды, потраченной на улучшения. Надетый предмет разобрать нельзя.
- В инвентаре до 500 предметов; лишние новые предметы сразу превращаются в руду.

## Где брать

- Первая победа на этапе кампании — гарантированный случайный предмет; редкость по главе:
  1 — обычный, 2–3 — редкий, 4–5 — элитный. Последний этап главы — ещё +20 осколков наследия.
- AFK-сундук: +2 руды в час и 1 предмет за 2 часа (обе ставки растут с прибавкой за пройденные этапы).
- Один раз всем (и уже существующим игрокам): по 4 обычных предмета каждого типа — 12 штук.

## Уникальный предмет героя

- Открывается на ступени «Миф», уровни 0 … 10, каждый уровень +3% ко всем характеристикам героя.
- Уровень 5 — ультимейт сильнее на 10%, уровень 10 — на 20% (урон, лечение, щиты ультимейта).
- Цена L→L+1: осколки наследия `10 + 5 × L`, золото `2000 + 2000 × L`.

## Экраны

- **Инвентарь** (кнопка внизу главного экрана): фильтры по слоту и редкости, улучшение +1 / +5, разбор,
  «Разобрать обычные».
- **Герои**: 4 ячейки снаряжения (нажатие — выбор подходящих предметов, лучшие сверху), «Надеть лучшее»
  (из свободных предметов, у других героев не забирает), «Снять всё», уникальный предмет.

## API

| Метод | Путь | |
|---|---|---|
| GET | `/api/v1/inventory` | Предметы, кошелёк, справочники (выдаёт стартовый набор) |
| POST | `/api/v1/items/{id}/upgrade` | `{times}` — улучшить |
| POST | `/api/v1/items/dismantle` | `{ids: [...]}` — разобрать в руду |
| POST | `/api/v1/heroes/{id}/equip` | `{item_id}` — надеть (с другого героя — переходит) |
| POST | `/api/v1/heroes/{id}/unequip` | `{slot}` или `{}` — снять одно / всё |
| POST | `/api/v1/heroes/{id}/auto-equip` | Надеть лучшее |
| POST | `/api/v1/heroes/{id}/signature` | Улучшить уникальный предмет |

Миграция базы `0006`: таблица `player_items`, уровень уникального предмета у героя, доли руды и предметов в сундуке.
При вознесении и роспуске снаряжение «корма» возвращается в инвентарь.
