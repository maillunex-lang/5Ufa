# Обновление приложения из самой игры

Когда выходит новая версия APK, игра сама предлагает обновиться: скачивает APK с сервера
(с докачкой и проверкой SHA-256) и открывает стандартный установщик Android.

## Как это устроено

```
push в main (client/) → GitHub Actions: сборка APK → подпись → Releases
                                                     └→ загрузка APK на сервер (PUT /api/v1/client/releases/N)
Игра при запуске → GET /api/v1/client/latest?code=<номер сборки>
   ├─ нет новой версии        → обычный запуск
   ├─ новая версия            → на главном экране окно «Новая версия» [Обновить] [Позже]
   └─ обязательная версия     → экран обновления, без него в игру не пустит
```

- APK хранится на сервере в общем хранилище контента (по SHA-256), раздаётся Nginx с докачкой.
- Репозиторий приватный, поэтому телефоны качают APK **с вашего сервера**, а не с GitHub.
- Номер сборки (versionCode) = номер запуска сборки в GitHub Actions; он только растёт.

## Первичная настройка (один раз)

Токен загрузки скрипт деплоя создаёт на VPS сам. Нужно только добавить его в GitHub.

На VPS:
```bash
grep '^CLIENT_UPLOAD_TOKEN=' ~/ufagame/.env | cut -d= -f2
```
Выведется строка из 64 символов (буквы a–f и цифры).

GitHub → **Settings → Secrets and variables → Actions → New repository secret**:
- Name: `CLIENT_UPLOAD_TOKEN`
- Secret: эта строка

## Выпуск обновления

Обычно ничего делать не нужно: любой push в `client/` собирает APK и выкладывает его.

Вручную (например, чтобы указать «Что нового» или сделать обновление обязательным):
GitHub → **Actions → APK → Run workflow** → заполните поля → **Run workflow**.

## Управление версиями на VPS

```bash
cd ~/ufagame
docker compose exec api python -m app.cli client list               # все загруженные версии
docker compose exec api python -m app.cli client set 12 mandatory   # сделать версию 12 обязательной
docker compose exec api python -m app.cli client set 12 optional    # снова необязательной
docker compose exec api python -m app.cli client set 12 disable     # откатить: игрокам не предлагать
docker compose exec api python -m app.cli client set 12 enable      # вернуть
```

## Что увидит игрок

1. Окно «Новая версия 0.1.N» с описанием и размером → **Обновить**.
2. Полоса загрузки (при обрыве связи продолжится с того же места).
3. Android откроет установщик → **Установить**.
4. **Первый раз** Android спросит разрешение «Установка неизвестных приложений» для этой игры:
   откроются настройки → включите переключатель → вернитесь назад → нажмите **Обновить** ещё раз.
   Это делается один раз.

> Версия 0.1.2, которую вы уже установили, ещё не умеет обновляться сама.
> Следующую версию (с этой функцией) нужно поставить вручную из Releases — дальше обновления пойдут из игры.
