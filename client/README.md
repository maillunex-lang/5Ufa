# Клиент (Godot 4.4, Android, вертикальная ориентация)

Статус: **C-1…C-3 (первая версия)** — вход, главный экран (город с подписанными зданиями, верхняя панель, меню, нижние вкладки Город · Кампания · Герои · Инвентарь), кампания с расстановкой 2+3, герои с прокачкой и сбросом, воспроизведение боя с сервера.

**Временное:** вместо моделей героев цветные капсулы, вместо рисованного фона плитки и плоская арена (нужна графика из трека D). Не сделано: привязка аккаунта и восстановление, обучение, докачка ресурсов, обязательное обновление, скорость x2/x4, настройки/почта/задания (пункты меню отключены) — C-4, C-5.

- Адрес сервера: константа `DEFAULT_SERVER_URL` в `api.gd` (для тестов переопределяется переменной `FIVEUFA_SERVER`). Токен хранится в `user://session.cfg`.
- Клиент ничего не считает: бой и награды приходят с сервера (`docs/api.md`).
- APK собирает GitHub Actions (`.github/workflows/client.yml`); тестовый APK появляется в Releases как prerelease. Подпись тестовая, см. `deploy/test-signing/README.md`.
- Локально: Godot 4.4.1, открыть папку `client/`.
