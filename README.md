# 5Ufa

Онлайн-RPG 5×5 для Android (Godot) с серверным автобоем. Спецификация v1.0 от 04.11.2026.

| Каталог | Что внутри | Статус |
| --- | --- | --- |
| `server/` | Node 22, без внешних зависимостей (встроенный SQLite): аккаунты, прогресс, серверная симуляция боя, награды, админ-API | работает, 14 тестов |
| `admin/` | Адаптивная веб-админка (сейчас: состояние, техработы, бэкап, перечитать контент) | каркас |
| `content/game.json` | **Тестовые** герои, враги, 10 этапов, прогрессия | тестовые значения |
| `scripts/`, `.github/workflows/` | Автодеплой на VPS при push в main | не проверено на VPS |
| `client/` | Godot-проект: вход гостем, связь с сервером, пробный бой текстом | C-1 готов, APK собирается в Actions |

## Локально
```
cd server && npm test        # тесты
npm run economy              # проверка, что тестовых наград хватает на прохождение
npm start                    # http://localhost:8080 , админка: /admin/
```
Деплой, адрес и пароль владельца: [docs/deploy.md](docs/deploy.md). Правила боя и принятые решения: [docs/battle-rules.md](docs/battle-rules.md).
