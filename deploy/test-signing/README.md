# Тестовая подпись APK

`test.keystore` (пароль `android`, alias `androiddebugkey`) — **только для тестовых сборок**: лежит в публичном репозитории, поэтому не защищает ничего.
Она нужна, чтобы тестовые APK подписывались одним и тем же ключом и ставились поверх друг друга без удаления.

**Боевой ключ подписи** (этап 6/9) создаётся отдельно, хранится в GitHub Secrets и в резервной копии у владельца и в репозиторий не попадает. Приложение, подписанное тестовым ключом, нельзя обновить боевым — это отдельное приложение.
