# Правила для ИИ-разработчиков и людей (5Ufa)

Спецификация игры — раздел «Требования» в `docs/ROADMAP.md` и файл спецификации v1.0 владельца. Работа идёт параллельно по **трекам** (см. `docs/ROADMAP.md`).

1. **Один трек — своя папка.** Не правьте файлы чужого трека. Нужна правка там — опишите в issue или в PR отдельным файлом `docs/requests/<трек>-<тема>.md`.
2. **Общий контракт** — `docs/api.md` и `content/game.json` (схема в `server/src/content.js`). Меняете контракт — меняйте в том же PR документ и тесты, и помечайте PR меткой `contract`.
3. **Ветки:** `ai/<имя-агента>/<короткая-задача>`. Прямых пушей в `main` нет, только PR. `main` деплоится на VPS автоматически, поэтому он всегда должен быть зелёным.
4. **Перед PR:** `cd server && npm test && npm run economy`. Для клиента и админки — проверка, описанная в вашем треке. PR маленький и законченный, в описании: что работает, как проверено, что не проверено.
5. **Секреты:** никаких паролей, токенов, ключа подписи, данных игроков в репозитории и в логах. Репозиторий публичный.
6. **Лицензии:** чужие ресурсы только с записью источника и лицензии в `docs/licenses.md`. Фоны Kalponic не выкладывать в репозиторий (см. спецификацию, раздел 9).
7. **Числа баланса** хранятся в данных (`content/`), помечены тестовыми, пока владелец не утвердил.
8. **Не имитировать готовность:** заглушки помечайте явно, недоступные системы не рисуйте работающими.
9. Не трогайте `/root/ufagame` на VPS и чужие проекты на нём. Деплой только через `scripts/deploy.sh` (GitHub Actions).
