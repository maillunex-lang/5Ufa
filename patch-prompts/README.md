# Справочник промптов для ИИ

Здесь будут готовые промпты для каждого раздела контента: герои, фракции, кампания,
снаряжение, призыв, магазины, локализация, интерфейс, звуки и т.д.

Каждый промпт содержит:
1. Задачу для ИИ.
2. Текущую JSON Schema раздела (из `/shared/schemas`).
3. Пример данных.
4. Правила именования файлов и структуру ZIP (см. `docs/patch-format.md`).

Кнопка «Промпт для ИИ» в админке собирает такой же промпт автоматически из актуальной схемы.
Файлы `<раздел>.md` собраны по базовому контенту скриптом `scripts/gen_patch_prompts.py`;
кнопка в админке даёт тот же промпт с учётом ваших правок.
